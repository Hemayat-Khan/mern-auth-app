# MERN Auth App

A simple login and signup application built with the MERN stack (MongoDB, Express, React, Node.js), using JWT-based authentication.

## Features

- User signup and login
- JWT authentication with token stored in Redux
- Encrypted/hashed passwords
- MongoDB Atlas database
- Express REST API

## Tech Stack

- **Frontend:** React (Vite), Redux
- **Backend:** Node.js, Express
- **Database:** MongoDB Atlas
- **Auth:** JWT, bcrypt

## Getting Started

1. Clone the repo
https://github.com/Hemayat-Khan/mern-auth-app.git

2. Install dependencies (in both `backend` and `frontend` folders)

3. Add a `.env` file in the backend folder
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret

4. Start the backend
cd Backend
npm run dev

5. Start the frontend
cd my-react-app
npm run dev
